# Cute Pigeons 1.0.0

Minecraft 1.20.1 / Forge 47.x.

Features:
- Cute flying pigeon entity.
- Natural Overworld spawning in flocks of 3-6.
- Seeds tame pigeons (wheat, beetroot, pumpkin and melon seeds).
- Tamed pigeons follow their owner when far away.
- Untamed pigeons naturally flock and wander through the air.
- Spawn egg: `cute_pigeons:pigeon_spawn_egg`
- Give command: `/give @s cute_pigeons:pigeon_spawn_egg`
